# Nova — Week 1 Responsive Landing Page

A responsive landing page created with semantic HTML5, modern CSS (Grid/Flexbox), media queries, and vanilla JavaScript.

## Files
- `index.html` — semantic page structure and content
- `style.css` — responsive visual design
- `script.js` — accessible mobile navigation toggle

## Run
Open `index.html` in any modern browser. No build tools or external libraries are required.

## Responsive behavior
- Desktop: two-column hero, three-column feature grid, full navigation.
- Tablet: stacked hero and feature cards.
- Mobile: compact typography, stacked content, hamburger navigation menu.
- Reduced-motion preference is respected.
