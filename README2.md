# Pulse — Week 2 Interactive UI Component

## Component
Accessible responsive tabs built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Semantic ARIA tablist/tab/tabpanel pattern.
- Click and full keyboard support: Arrow keys, Home, End, Enter and Space.
- Responsive desktop/tablet/mobile layout.
- Focus-visible styling and live selection announcements.
- Reduced-motion support.
- Defensive JavaScript validation and console error handling.
- `<noscript>` fallback when JavaScript is unavailable.
- Additional Settings toggles demonstrate reusable DOM state updates.
- No frameworks, libraries or build tools.

## Test
1. Extract the ZIP and open `index.html`.
2. Click each tab and verify the matching panel.
3. Use Tab, Arrow keys, Home, End, Enter and Space.
4. Resize to mobile and tablet widths.
5. Test both Settings checkboxes.
6. Enable reduced motion and confirm functionality remains.
7. Disable JavaScript and verify the fallback message/content.
8. Check the browser console for errors.
9. Inspect ARIA attributes with browser accessibility tools.

## Files
`index.html` = structure; `style.css` = responsive UI; `script.js` = interaction/keyboard/error handling; `README.md` = documentation.
